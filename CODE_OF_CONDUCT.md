# Code of Conduct

## Our Standard

HOSC contributors are expected to keep project communication respectful,
technical, and focused on improving the codebase.

Expected behavior:

- Be clear and constructive in issues, reviews, and discussions.
- Critique code and design decisions, not people.
- Assume good intent, but address harmful behavior directly.
- Keep public discussions appropriate for a broad open-source audience.
- Respect maintainers' decisions on scope, priorities, and release timing.

Unacceptable behavior:

- Harassment, threats, insults, or personal attacks.
- Discriminatory language or conduct.
- Publishing private information without consent.
- Repeated off-topic disruption after maintainers ask for it to stop.
- Abusive review behavior that blocks productive collaboration.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or restrict
participation when behavior violates this code of conduct.

Report serious issues privately to the maintainer contact listed by the
repository owner.

## Attribution

This policy is inspired by common open-source codes of conduct and adapted for
the current HOSC project.
